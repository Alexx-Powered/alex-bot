# 聊天自然感与长期记忆调研

调研日期：2026-10-29。范围是源码与公开一手资料，没有读取DSH私人角色配置、会话原文或密钥。

## DSH QQ 的差异

本机能找到DSH核心运行时，未找到已安装的dsh-qqbot插件包，所以QQ插件部分依据腾讯官方源码审阅，不能把某个实际实例的聊天表现归因于默认设置。

- [scope prompt与会话恢复](https://github.com/tencent-connect/dsh-qqbot/blob/main/src/session/session-manager.ts)：按群/私聊注入配置，复用现有会话、从磁盘恢复，再新建会话；支持压缩。`groupPrompt/directPrompt`是可定制入口，没有发现默认“人味聊天语录”。
- [官方运行配置](https://github.com/tencent-connect/dsh-qqbot/blob/main/cordis.yml)：持久会话与压缩比每次重新开始更利于接住前文。它不等于有选择的个人偏好长期记忆。
- 本机`@deepseek-ai/dsh-persona`将角色作为独立系统段，标准preset主要是coding-agent身份。QQ分段器主要处理字符上限与结构，不是通过随机延迟/连发假装真人。

## 原实现的问题

1. 系统提示先强调工具分流，再堆权限规则，角色放在最后；容易形成客服语气。
2. “代码/编程/部署”等名词就能触发前置拒绝，正常工作吐槽根本进不了模型。
3. 私聊只保留3轮/15分钟，重启或修改策略即失去上下文。群聊10条/30分钟是匿名短背景，也不等于长期记忆。
4. 全靠模型可选记忆参数会漏记。真实模型测试已复现“答应称呼但重启后不记得”，因此不能只看mock通过。

## 本轮修改

- `chat_persona.py`独立表达风格并前置；聊天可以短反应，避免硬安慰、说教、固定结尾邀请和复述。首版用户确认“记忆正常，口吻还要调整”，随后明确选择可爱、淘气、兼有体谅的大肥鱼：QQ短句少句号，能按情绪灵活卖萌、用~或小表情。Python输出层原本会把所有换行压成空格，本轮同步保留自然换行；未按关键词机械删标点或强制每句加符号。
- 继续叠主路由提示词后，真实输出仍容易多解释能力和惯性追问，因此普通chat增加一次独立、无工具的表达调用：只看当前消息、必要近期上下文和当前分区偏好，不传业务prompt、工具schema或首轮客服草稿。它不能改topic、权限或记忆；失败保留已校验首轮回复。查看/删除记忆与写入失败回执直接返回，不经过润色。普通聊天因此多一次短模型调用，记忆抽取本身仍不单独调用模型。
- 输入检查判断明确技术任务，不再按技术名词拒绝吐槽。实际命令、代码产出、附件与敏感注入边界保留。
- 私聊近期上下文8轮/2小时，仍为有界进程内历史；没有把所有聊天原文永久保存。
- 按用户选择，自动保存本人本轮自述的称呼、稳定喜好、回复风格和长期项目。明显自述由固定规则提取，模型也可在同轮`reply_chat`附上原文片段；都经过同一LangChain Tool校验，不额外调用记忆模型。
- 长期事实用SQLite保存，路径固定`.private/chat-memory/chat-memory.sqlite3`。目录0700/文件0600，数据并非数据库字段加密；整体备份另做加密。最多24条/分区、256分区、180天有效、数据库4MiB上限。
- `sessionKey`区分本人私聊、不同群、群内不同成员。模型无法指定分区、路径、SQL或其他用户；灰名单可使用个人聊天记忆，业务权限不变。
- 只记可验证的本轮自述片段，不记账号、密钥、联系方式、健康隐私、金额余额、天气与教室状态，不从其他成员背景或模型回复提取。
- 支持自然提问“你记得我什么”“忘掉猫的偏好”“忘掉这条”“清空我的记忆”。“这条”在无明确关键词时指自己最近保存的一条；清除后也丢弃当前短期背景，避免刚删的事实被上下文带回来。
- 长期事实作为不可信Human JSON参考，不能覆盖权限、固定比例或工具事实；当前用户的更正优先。资料可能过时，不承诺从片段推断完整个人画像。
- 备份使用SQLite一致性快照，再进入原整体加密备份；不直接复制正在写入的数据库文件。

## 验证方法

离线测试涵盖真实LangChain调用、跨Runner重启、原文校验、私聊/群/成员隔离、灰名单权限、过期/容量、错误存储、忘记及群背景清除。真实DeepSeek评测使用隔离的合成用户和独立存储，不向QQ发送消息，并检查新进程能够回忆称呼、清空后新进程没有该记忆。语气改善属于小样本观察，仍需用户真实聊天体验验证，不能用一组模型输出保证所有表达都自然。
