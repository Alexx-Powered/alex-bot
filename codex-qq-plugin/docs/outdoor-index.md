# 户外指数 v3（2026-11-03）

用户确认的自定义评分，用于单城市两日天气图中的第 1 日。全部按北京时间：上午 06:00–12:00、下午 12:00–18:00，分别评分，图片采用两段中的较高分。全天仅表示这两个白天时段，不含夜间。忽略温度，不作为官方气象预警或健康指数。

计算位于 `python/outdoor_index.py` 的参数受限 LangChain Tool；仅接收日期和至多 48 条公开小时预报，不调用模型、网络、文件、命令或收件人接口。Node 只按城市、时间戳对齐 ECMWF 与 CAMS 数据，校验有限返回值并绘图。普通查询、明天天气和逐群早间天气共用结果；不更改订阅和投递幂等。

## 评分

从 100 分减去各项扣分，下限为 0。云量取时段平均，PM2.5、平均风速、阵风各取时段峰值，雨量取时段累积并结合小时峰值和天气代码。

| 项目 | 标准 |
| --- | --- |
| 云量 | 0 / 10 / 20 / 50 / 100% 分别扣 0 / 3 / 6 / 10 / 15 分，档间线性插值 |
| PM2.5 | 0 / 60 / 100 / 150 μg/m³ 分别扣 0 / 5 / 45 / 100 分，档间线性插值；≥150 时该时段直接 0 分 |
| 风力 | 低于蓝色门槛不扣；蓝色扣 25，黄色扣 55，橙色及以上该时段直接 0 分 |
| 零星小雨 | 有雨至多 2 小时、累计≤0.5 mm、小时峰值≤0.2 mm，扣 20 |
| 其它小雨 | 累计≤2 mm 且小时峰值≤0.5 mm，扣 35 |
| 小雨偏多 | 其余未触及清零门槛的雨，扣 50 |
| 中雨及以上 | WMO 63/65/67/81/82，或半天累计≥5 mm、任一小时>2.5 mm，该时段直接 0 分 |

风力参照国家大风预警的风力等级门槛：蓝色平均风≥10.8 m/s 或阵风≥13.9；黄色平均风≥17.2 或阵风≥20.8；橙色平均风≥24.5 或阵风≥28.5。按命中的最高档计算。这是预报数值比对，未查询官方实际发布的预警，不能将结果称为已发布预警。来源为已核对的中国气象局《气象灾害预警信号发布与传播办法》附件：<https://www.cma.gov.cn/zfxxgk/gknr/flfgbz/gz/202005/P020220628619411458474.pdf>。

## 档位与文案

- ≥80：夯；60–<80：可；<60：拉。先按未四舍五入的分数分档，展示一位小数。
- 金色夯（夯中夯）：≥95，云量≤5%，PM2.5≤25，平均风峰值≤5.4 m/s、阵风峰值≤7.9 m/s，且无雨。
- 两段均≥80：全天宜户外活动；仅一段≥80：该时段宜户外活动。无夯但有可时显示对应时段“户外条件尚可”。两段均拉时显示“全天不宜户外活动”。
- 任一时段缺少完整 6 小时关键数据，或遇尚未定义规则的雪、冻毛毛雨、雷暴等天气，整日不选出最高档；图片显示暂不评级，分时段注明原因。已存在规则的强冻雨代码 67 按中雨以上归零。

## 渲染与运维

沿用用户确认的深青天气卡片和 1867 像素宽度，原狂草素材存放 `public/weather-report/outdoor/`，原始哈希见 `provenance.json`。金色由原夯字透明度着色。大字在卡片内以 18% 透明度延续，户外指数标题不透明；时段高亮为米色建议条的真实镂空。删除 48 小时徽标和图标下方重复天气描述。

`renderWeatherReportImage` 为异步图像生成接口。普通天气与早报的重型绘制共用既有串行队列。画布按最多 512 像素高分块绘制，再以 16 行条带、Sub 过滤与 zlib 无损压缩拼接，避免整图画布和编码副本同时驻留；画布及笔画临时存储用完释放。保留总像素与版式，极少量裁切边界的抗锯齿舍入允许最大 19/255 色阶、变化像素少于 0.01%、平均每通道误差小于 0.001。部署前使用 ECS 独立 128 MiB/零 swap/CPU 50% 专项验收，不为通过测试放宽限额。
