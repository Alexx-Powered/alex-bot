## 监控范围

- Node记录随机请求UUID、场景枚举、core排队、业务总耗时、worker排队/总耗时、QQ发送。
- Python LangChain callback只抽取模型段耗时、输入/输出/cache-read token数；初始化、记忆与工具耗时分别记。stdout返回新增可选timings，不改变既有结果kind。
- 预热或复用进程的stdout回调使用每个任务捕获的AsyncLocalStorage上下文，避免把后续请求记到第一条。
- Python相对时间重建模型串行时间线，不把两次模型都画成同时结束。
- 上传时同时提供`trace_id`与SDK兼容的`dotted_order`：root为自身时间/UUID，child为root段加子段。真实Cloud首次返回400后，安全诊断确认缺少这组配套字段；补齐后同样的空正文验证得到202，未更换用户Key。
- 本地`.private/telemetry/recent.json`保留最近50条，目录0700、文件0600，包含P50/P95和分段摘要；这只是小窗口统计，不是长期SLA。
- 监控自检显式标记synthetic，仅用于验证上报，在最近记录里可辨识，不计入业务P50/P95。旧版本仅agent的自检记录也从业务统计剔除，避免毫秒级自检拉低真实QQ耗时。
- 普通无前缀群背景不产生追踪；有模型/业务执行或实际响应的请求才记录。

## LangSmith 配置与隐私

配置页第07节可填自己的Key、项目、区域、必要时workspace UUID。Key通过现有平台加密保存到`.private/monitoring-config.json`，不回显，不进入Python、模型输入、日志或trace。Key纳入整体加密备份。

Node 在请求完成后向已配置的 LangSmith 项目发送分段记录。Python 继续关闭自动追踪，单独提供阶段耗时、分类后的异常和 HTTP 状态。[LangSmith run 格式](https://docs.langchain.com/langsmith/run-data-format)

- 从 2026-11-05 起，远端 Input 显示已授权且唤醒机器人的本条消息原文。部分工具步骤显示地点、图层、时长等已校验参数。可识别的凭据、绑定口令与 QQ 内部提及标识会遮盖。背景群聊、完整模型提示、历史消息、附件和工具输出均排除在上报范围外。
- Error Message 显示失败步骤、已识别的错误码、中文原因，以及上游提供的 HTTP 状态。备用源成功时，原数据源步骤保留故障原因，根请求显示成功。SDK 原始响应、堆栈和凭据不上报。本地最近记录仍只保存性能统计，历史远端记录不会回填。
- 仅允许US/EU官方HTTPS API，workspaceId用官方`x-tenant-id`。独立有界队列32条，单次POST限2秒、不重试，不等待网络或磁盘再返回QQ。
- 失败、未配置、断网或监控拥堵只影响追踪状态，不暂停Bot，不消耗QQ发送额度。

开启后可以点击“验证LangSmith（不发QQ）”，或让维护者调用受管理员认证的`POST /api/monitoring/test`。返回QUEUED只表示入队，须看到远端SENT与LangSmith项目中的trace才能确认接入。若仅有本地记录或401/403，不能声称远端已接通。API仅本人本机设置页管理，集成令牌不允许访问监控配置。

本轮已经完成真实验收：用户自行配置Key并启用；Bot正式上报SENT，真实QQ请求产生的根/模型/QQ发送追踪可从LangSmith按UUID回读，关系正确且输入输出无内容，用户确认在LangSmith中“可以看到”。Key所在配置AES-256-GCM、文件0600，17文件整体加密备份已下载本机并通过内存恢复校验，无明文落盘。最终发布版本/PID与测试数以`../deploy/latency-monitoring-20261029.json`为准。

## 本轮优化与后续判断

2026-10-29 的优化在生产启动时、连接QQ前导入Python/LangChain/provider依赖，不创建模型、不发API请求、不写业务记忆。HTTP连接池空闲复用从默认5秒延至60秒；当时仍为20秒超时。2026-11-03 后续优化将模型等待改为30秒，并增加明确天气请求的 Python 确定性快捷路径；详情见 HANDOVER 最新节。无超时自动重试，固定工具、权限、口吻与长期记忆继续保留。

全局任务队列仍串行，长校园查询可能让后续聊天等待；先根据core_queue与worker_queue的真实指标决定是否需要拆队列，没有在本轮贸然开放并发。普通聊天两次模型请求也仍然存在，约2秒热路径的进一步优化需要继续权衡路由准确率、口吻与成本。
