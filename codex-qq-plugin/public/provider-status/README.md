# Provider marks

Unmodified official marks used only to identify the service being queried.
Retrieved 2026-11-03; exact source URLs and file hashes are in `sources.json`.
DeepSeek's official ICO was losslessly converted to PNG, without resizing or
recoloring. Other files retain their original formats. These assets do not
replace the bot's own logo elsewhere.

The user requested Kimi to fill the status card's rounded logo frame. Its source
file remains intact; the renderer trims the 1-pixel square border and clips the
image to the existing frame, with no white inset. Used by the production renderer.

Main cards follow each provider's visual palette: OpenAI monochrome, DeepSeek
blue, Gemini blue/violet, Claude clay, Kimi black. Darker blue shades maintain
readable white body text; the logos themselves retain their official colors.
