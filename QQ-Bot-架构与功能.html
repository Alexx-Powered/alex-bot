00 / SYSTEM OVERVIEW

先看一条请求如何走完

Node 管接入与交付，Python 管 Agent 与新增业务规则；两端通过 JSON 行协议协作。

固定请求：更短的执行链

例如“查 Claude 状态”“发 动态云图 北京”，解析参数后直接 invoke 工具。部分完整天气自然句也有 Python 快捷路由。

自然语言：结合上下文作决策

例如多轮追问、换话题和模糊表述，通过 Agent 选择工具或澄清，再按业务需要返回事实或解释。

核对基线：当前工作区源码 + HANDOVER.md 的 2026-11-05 发布记录。源码细节与已部署证据分开标注；本页不是实时服务状态面板。

会话内：短期信息

聊天上下文、当前附件、工具原始量与结果。用于接话和追问，受条数、容量及 TTL 限制。

跨重启：持久信息

SQLite 成员记忆；JSON 配置、校园日期快照、投递与限额状态。随备份机制保留。

可重建：数据与产物

地点目录、地图资产与空间索引；短期气象缓存、视频成片和临时帧。按用途更新或回收。
