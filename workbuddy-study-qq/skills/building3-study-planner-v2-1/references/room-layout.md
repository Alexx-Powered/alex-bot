# 三号楼换教室位置关系

来源为用户提供的《三号楼教室分布图》。下列相邻是根据同翼、走廊相对位置整理的粗略分组，不是门到门距离测量。其中**126↔120算相邻**由用户明确指定。同一组内的房间可按相邻/同一区域优先规划。

| 楼层 | 相邻/同一区域组 | 走廊连接的相邻对 |
|---|---|---|
| 一层 | 西翼：104、105、106、107、113；东翼：119、120、123、125、126、127、128；中东侧：117、130、131 | 103↔102、102↔101、101↔131、131↔130、130↔129、103↔104、103↔113、129↔128、129↔119 |
| 二层 | 中东侧：209、214、215 | 203↔202、202↔201、201↔215、215↔214 |
| 三层 | 中东侧：308、313、314 | 302↔301、301↔314、314↔313、313↔312 |
| 四层 | 中东侧：406、409、410 | 402↔401、401↔410、410↔409、409↔408 |

相邻不是传递关系：A邻B且B邻C，不表示A邻C。上表之外的同层房间视为“同层较远”；不同楼层视为“跨楼层”。图中未收录的房间可以列其截图可用情况，但换房距离标“位置待确认”。

通常先少换房，再按位置已知、少跨层、相邻优先排序，最后比较小教室使用节数。不要把107↔117仅因都在一层就说成相邻，也不要因126和120差6就说距离远。8间老旧大教室不参与任何路径。

房间布局只用于路线选择，不能证明当天教室开放，也不能证明有空座；当天是否空闲以截图的已确认课节为准。
